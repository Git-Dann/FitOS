# Build

FitOS is a Next.js App Router browser prototype built with TypeScript and Tailwind CSS. It uses deterministic local data only.

## Commands

- `npm run dev` — local development server
- `npm run build` — production build
- `npm run lint` — static lint checks
- `npm run test:rules` — adaptive-fulfilment rules tests
- `npm test` — build plus rendered HTML smoke test

## Routes

- `/` marketing site
- `/platform` platform explanation
- `/demo` guided presenter controller
- `/demo/customer`, `/demo/associate`, `/demo/manager` role surfaces
- `/pilot` pilot and commercial story
